# Agents

This folder contains lightweight Markdown guides for repo-specific subagent work.

These files are not used automatically by Codex. They exist so a human or agent can
reuse the same project context without rediscovering the basics each time.

## Suggested usage

- Read the relevant agent file before exploring or editing.
- Keep each file focused on one responsibility.
- Prefer practical notes: entry points, commands, constraints, and known risks.

## Current agents

- `repo-explorer.md`: Quick orientation guide for understanding this Gatsby site.
